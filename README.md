# SAP RAP PO Upload Workflow

Enterprise SAP RAP Purchase Order Upload & Approval Workflow using OData V4, Fiori Elements, Email Notification and BAPI Integration.

---

## Features

- Excel Upload
- RAP Managed Business Object
- OData V4 Service
- Fiori Elements UI
- Approval Workflow
- Email Notification
- Purchase Order Creation
- Status Management
- Background Processing Ready
- Validation & Error Handling

---

## Technologies Used

- SAP RAP
- ABAP RESTful Application Programming Model
- CDS Views
- Behavior Definitions
- OData V4
- Fiori Elements
- BAPI_PO_CREATE1
- SAPconnect Email

---

## Workflow

Upload Excel
→ Generate Items
→ Submit for Approval
→ Email Notification
→ Approve / Reject
→ Create PO Request
→ Background Processing
→ PO Creation
